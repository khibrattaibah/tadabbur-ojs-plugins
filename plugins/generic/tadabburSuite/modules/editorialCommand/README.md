# غرفة القيادة التحريرية — Editorial Command Center (OJS 3.5)

لوحة واحدة تعرض كل البحوث النشطة. تظهر أول بند في قائمة OJS لمدير المجلة والمحررين ومساعديهم.

## ما تعرضه
- **بطاقات سريعة:** عدد البحوث النشطة، والمتأخرة عن المهلة، ووسيط العمر منذ التقديم، والبحوث التي تنتظر قراري.
- **على من ينتظر البحث الآن؟** على المحرر، أو المحكّم، أو المؤلف، أو التحرير والإخراج. ويُعرض عدد المتأخر عند كل طرف.
- **توزيع البحوث على المراحل**، و**أعباء كل محرر**: البحوث المسندة إليه، وما ينتظر قراره، وما تأخر عنده.
- **جدول البحوث مرتبًا، المتأخر أولًا**، وفيه لكل بحث:
  - المرحلة وتاريخ دخولها.
  - ما ينتظره البحث الآن: تعيين محرر، أو القرار الأولي، أو دعوة محكّمين، أو رد المحكّم، أو تقارير التحكيم، أو القرار بعد التحكيم، أو تعديلات المؤلف، أو التدقيق اللغوي، أو الإنتاج.
  - مدة الانتظار، والمدة منذ التقديم، والمحرر المسؤول، وملخص التحكيم.
- **تصفية** حسب المرحلة أو الطرف أو المحرر أو المتأخرات، و**تصدير CSV**.

## الإجراءات
- **ذكّر المؤلف / ذكّر المحرر:** رسالة ثنائية اللغة قابلة للتعديل، تُرسل من بريد المجلة وتُسجّل في سجل مراسلات البحث.
- **الملخص اليومي (اختياري):**
  - يصل كل محرر بريدٌ بما ينتظره.
  - ويصل مديري المجلة بريدٌ بقائمة المتأخرات.
  - يعمل دون Cron: يُرسل مرة واحدة في اليوم مع أول زيارة للوحة بعد السادسة صباحًا.
  - ويمكن إرساله فورًا من صفحة الإعدادات.

## المهل (قابلة للتعديل)
| المرحلة | المهلة الافتراضية |
|---|---|
| تعيين محرر | 3 أيام |
| القرار الأولي | 7 أيام |
| دعوة المحكّمين | 7 أيام |
| القرار بعد التحكيم | 10 أيام |
| تعديلات المؤلف | 30 يومًا |
| التدقيق اللغوي | 21 يومًا |
| الإنتاج | 14 يومًا |

الحد الأدنى للمحكّمين: 2.

ويُعد المحكّم متأخرًا إذا تجاوز موعد الرد أو موعد التسليم الذي حدده OJS في مهمة التحكيم.

## ملاحظات
- لا تنشئ الإضافة جداول في قاعدة البيانات. تقرأ مباشرة من جداول OJS: القرارات، ومهام التحكيم، والإسنادات.
- تذكير المحكّمين يتولاه OJS آليًا، فلا تكرره الإضافة.
