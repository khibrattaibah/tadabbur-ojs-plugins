# مساعد الترجمة والملخصات — Abstract & Metadata Translation Assistant (OJS 3.5)

## ما يفعله
- **ترجمة** العنوان والعنوان الفرعي والملخص والكلمات المفتاحية بين العربية والإنجليزية، ويدعم لغات المجلة الأخرى أيضًا.
- **تدقيق لغوي** لنسخة موجودة، كالملخص الإنجليزي الذي كتبه المؤلف، مع مقارنتها بالأصل لكشف أخطاء الترجمة.
- **أعراف النشر الدولي:**
  - تُكتب المصطلحات العربية برومنة ALA-LC مع شرح موجز، مثل: tadabbur (reflective contemplation).
  - يُترجم معنى الآيات ويُذكر موضعها بصيغة (Q 2:255).
  - تُكتب الكلمات المفتاحية بأسلوب Title Case.
- **مسرد المجلة:** سطر لكل مصطلح بصيغة «عربي = English»، يلتزم به المساعد في كل مسودة، فتتوحد المصطلحات عبر الأعداد.
- **ملاحظات للمحرر:** يذكر المساعد المصطلحات والآيات والأعلام التي تحتاج تحققًا.

## اعتماد المحرر
- **المسودة لا تُطبَّق تلقائيًا.** يرى المحرر في صفحة المراجعة الأصل، والقيمة الحالية، والمسودة قابلة للتعديل، ويختار الحقول التي يعتمدها.
- **عند الاعتماد** تُكتب القيم في بيانات البحث للغة الهدف، وتبقى كلمات اللغات الأخرى المفتاحية كما هي.
- **البحوث المنشورة** لا تُعدَّل مباشرة. يُنشأ لها إصدار جديد من صفحة النشر أولًا، حفاظًا على سجل الإصدارات.
- **سجل المسودات** يحفظ لكل بحث المسودات المعتمدة والمهملة، مع النموذج المستخدم وعدد الرموز المستهلكة.

## الإعداد
- **مفتاح Claude API** من console.anthropic.com، والنموذج الافتراضي `claude-sonnet-5-5`، ويمكن تغييرهما من الإعدادات.
- **ما يُرسل:** العنوان والملخص والكلمات المفتاحية فقط. لا يُرسل ملف البحث ولا أسماء المؤلفين.
