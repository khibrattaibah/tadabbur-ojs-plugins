# جودة البيانات الوصفية وجاهزية الفهرسة — Metadata Quality (OJS 3.5)

لوحة «جودة البيانات والفهرسة» في قائمة OJS، يراها مدير المجلة والمحررون، وفيها:

1. **قائمة جاهزية المجلة (24 معيارًا):**
   - ISSN مع التحقق من رقم التحقق.
   - الناشر، والتواصل، و«عن المجلة» بكل لغة، والواجهة الإنجليزية.
   - سياسة التحكيم، وبيان الأخلاقيات (COPE)، والوصول المفتوح، والترخيص، وحقوق النشر، والخصوصية، ودليل المؤلفين، والرسوم، والأرشفة، وDOI، وOAI.
   - هيئة التحرير: حجمها وانتماءاتها وتنوعها الجغرافي.
   - تنوع المؤلفين، وانتظام الصدور، وإتاحة النص الكامل، وإضافة Google Scholar.

   كل بند موسوم بالجهة التي تشترطه (Scopus، WoS، DOAJ، Crossref، COPE)، ومعه رابط «إصلاح» يفتح الإعداد المعني.
2. **جودة بيانات كل بحث (24 فحصًا):** العنوان والملخص (الحد الأدنى للكلمات) والكلمات المفتاحية بكل لغة مطلوبة، وأسماء المؤلفين بكل لغة، والانتماء (بالإنجليزية أو ROR)، والدولة، وصحة ORCID بخوارزمية التحقق، والبريد المراسل، وDOI، والترخيص، والحقوق، والصفحات، والمراجع (وجودها، ورومنتها، وDOI فيها)، والعدد، والنص الكامل، وتاريخ القبول، وبيان التمويل.
   - درجة لكل بحث: 75٪ للحقول الإلزامية و25٪ للموصى بها.
   - تصدير CSV.
3. **بوابة النشر (اختيارية):** عند تفعيلها يرفض OJS نشر بحث ينقصه حقل إلزامي، ويعرض قائمة النواقص في نافذة النشر.

**الإعدادات (لمدير المجلة):** اللغات المطلوبة، والحد الأدنى لكلمات الملخص وللكلمات المفتاحية، واشتراط ORCID، والأقسام المعفاة (مثل الافتتاحية)، والبوابة.

**ملاحظة:** الدرجة مؤشر داخلي لا يضمن القبول في الفهارس. جهات الفهرسة تقيّم المحتوى والاستشهادات أيضًا.
