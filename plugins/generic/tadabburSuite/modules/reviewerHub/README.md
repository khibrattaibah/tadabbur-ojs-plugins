# مركز المحكّمين — Reviewer Hub (OJS 3.5)

## دليل المحكّمين
لكل محكّم مسجّل في المجلة يعرض الدليل:
- **بياناته:** الاهتمامات البحثية، والانتماء، والدولة، وORCID.
- **مؤشرات أدائه الفعلية من سجل التحكيم:**
  - عدد الدعوات وما اكتمل منها.
  - نسبة قبول الدعوات.
  - متوسط مدة التحكيم.
  - نسبة التسليم في الموعد.
  - تقييم المحرر للجودة (1–5).
  - العبء الحالي، والمتأخر.
  - تاريخ آخر دعوة.

**البحث والترتيب:** بحث بالاسم أو الجهة أو التخصص، وتصفية حسب الدولة أو المتاحين فقط، وترتيب حسب الأكثر تحكيمًا أو الأعلى جودة أو الأسرع أو الأقل عبئًا. ويمكن التصدير CSV.

**ملف لكل محكّم:** سجله الكامل في المجلة، أي البحوث والجولات والمدد والتوصيات والتقييمات.

**طلب تحديث الملفات:** رسالة جماعية ثنائية اللغة إلى المحكّمين الذين لم يسجّلوا اهتماماتهم، فبغيرها لا يمكن اقتراحهم آليًا.

## اقتراح المحكّمين لبحث
- **المطابقة:** تُطابق كلمات البحث المفتاحية وعنوانه وملخصه، بالعربية والإنجليزية، مع:
  - اهتمامات المحكّم.
  - البحوث التي حكّمها سابقًا في المجلة.

  والمطابقة تتجاوز اختلاف الهمزات والتاء المربوطة والحركات و«ال» التعريف.
- **الموازنة:** يرتفع ترتيب المحكّم بجودة تقاريره وسرعته، وينخفض بعبئه الحالي وكثرة اعتذاره وتأخره.
- **كشف تضارب المصالح:** يُستبعد المحكّم ويُذكر السبب إذا كان:
  - مؤلفًا في البحث.
  - من جهة أحد المؤلفين.
  - شارك أحد المؤلفين التأليف في المجلة.
  - مُسندًا إلى البحث نفسه سلفًا.
- **لكل اقتراح «سبب الاقتراح»** ظاهر، فيحكم المحرر بنفسه.
- **الإسناد يتم من صفحة البحث في OJS**، ليُطبَّق نظام الدعوات وقوالب البريد والمواعيد كما هو.

## ملاحظات
