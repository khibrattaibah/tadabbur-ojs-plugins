# قالب تدبر — Tadabbur Theme (OJS 3.5)

قالب فرعي (Child theme) من القالب الافتراضي لـOJS، بهوية مجلة تدبر ومكتب خبرات طيبة للبحوث والدراسات، للواجهة العامة ولوحة التحكم.

## ما يغيّره
- **الترويسة:** شعار المجلة واسمها وسطر تعريفي ورقما ISSN (الإلكتروني والورقي)، وشعار الناشر، وشريط علوي فيه تبديل اللغة وروابط الدخول، وقائمة رئيسة بلون الهوية. على الجوال: شعار مصغر وقائمة منسدلة.
- **الصفحة الرئيسة:** واجهة تعريفية فيها «قدّم بحثك» و«العدد الحالي» و«المحفوظات»، ثم بطاقات معلومات المجلة (ISSN، والتحكيم، والدورية، والوصول المفتوح، والرسوم، والناشر، وسنة التأسيس)، ثم العدد الحالي، ثم بطاقات السياسات التسع، ثم الإعلانات، ثم الفهارس.
- **صفحة البحث:** العنوان والملخص والكلمات المفتاحية باللغة الأخرى، وتاريخ البحث (الاستلام والقبول والنشر)، وزر نسخ رابط DOI، وتخطيط مرن بعمودين.
- **التذييل:** بيانات المجلة، وروابط السياسات، والتواصل، والترخيص، والفهارس، وحقوق الناشر.
- **محركات البحث:** بيانات منظمة JSON-LD من نوع Periodical للمجلة وScholarlyArticle للبحث، إضافة إلى وسوم Google Scholar التي تضيفها إضافتها.
- **لوحة التحكم** (المدير والمحرر والمحكّم والمؤلف): ألوان الهوية وخط IBM Plex Sans Arabic. يُولَّد ملف الأنماط تلقائيًا من `styles/build.css` المثبت مع الحفاظ على ترتيب قواعده، ويُحفظ في `cache/`.
- **سهولة الوصول:** تباين ألوان مطابق لـ WCAG AA، وإطار تركيز ظاهر، واحترام إعداد «تقليل الحركة»، ووسوم lang وdir للمحتوى ثنائي اللغة، وأنماط مخصصة للطباعة.

## التثبيت
1. الإعدادات ← الموقع ← الإضافات ← **رفع إضافة جديدة** ← `tadabbur.tar.gz`.
2. فعّل «قالب تدبر» من قائمة **Theme Plugins**.
3. الإعدادات ← الموقع ← **المظهر** ← اختر «قالب تدبر» واحفظ، ثم املأ الخيارات: السطر التعريفي، والناشر، ودورية الصدور، ونوع التحكيم، والرسوم، وسنة التأسيس، والفهارس، وروابط السياسات.
4. يقرأ القالب ISSN والترخيص والعنوان والبريد من إعدادات المجلة نفسها (المجلة ← الناشر/التوزيع).

## روابط السياسات
تذهب بطاقات السياسات افتراضيًا إلى صفحات OJS («عن المجلة» مع مرساة القسم، و«هيئة التحرير»، و«طلبات النشر»، و«الخصوصية»). إن كانت لديكم صفحات مستقلة (Static Pages) فاكتب في خيار «روابط السياسات» سطرًا لكل رابط بالصيغة:
```
review|https://tadabburmag.sa/tadabburmag/ar/review
ethics|https://tadabburmag.sa/tadabburmag/ar/ethics
```
المفاتيح المتاحة: aims, board, review, ethics, openaccess, guidelines, apc, archiving, privacy

## ما يتطلبه Scopus وWoS من الموقع (يُكمل من إعدادات المجلة)
بيان التحكيم، وبيان أخلاقيات النشر وسوء الممارسة، وصفحة رئيسة باللغة الإنجليزية، وعناوين وملخصات إنجليزية لكل بحث، وهيئة تحرير مع انتماءاتها، وانتماءات المؤلفين، وISSN، وانتظام الصدور، ونشر المحتوى كاملًا على الموقع. القالب يُظهر هذه العناصر ويسهّل الوصول إليها، لكن **محتواها مسؤولية المجلة**. وفي خيار الفهارس لا تُذكر إلا جهة مفهرسة فعلًا.
